Policy

模板沉淀口径

当前版本不做模板表和发布流。官方模板仍来自代码注册表；我的模板先用保存 Flow 作为候选资产。
1. Good Case成功或修复成功的真实 Run，包含日志、artifact 和业务结果。
2. 脱敏清洗去除客户数据、账号信息、真实链接和偶发执行痕迹。
3. 抽象模板保留稳定任务骨架、输入槽位、节点链路、guardrails 和默认 prompt。
4. 人工发布通过 validator 和真实 case 回归后，再进入官方模板列表。

Case Driven

优化保存 Flow

当成功 case、失败 case、修复记录和 artifact 摘要足够后，可生成候选优化。当前版本只展示入口，不自动发布。
1. 选择保存 Flow从我的 Flow 中选择要优化的稳定版本。
2. 汇总 case lessons查看成功、失败和 repaired case 的共性问题。
3. 生成优化候选LLM 输出候选 Flow 或模板 patch，并经过 validator。
4. 人工确认发布用户对比旧版和新版后，显式保存为新版本。
