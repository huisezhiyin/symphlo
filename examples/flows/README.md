# Flow Examples

The Local Alpha exports the exact selected multi-Agent writing definition as
`evidence/flow.json` on every run.

Three profiles demonstrate task-granularity choices:

- `multi-agent-writing-compact@1.0.0`
- `multi-agent-writing-balanced@1.0.0`
- `multi-agent-writing-fine@1.0.0`

They are independently immutable definitions over the same Runtime and Artifact
contract. They are intentionally generated from the validated Python contract
in A1; importing external Flow JSON is a later capability.
